격자 콜로니 계수

제작·배포 SEOL(신승근)
멤브레인 필터 배지 사진을 보면서, 인쇄된 격자 칸별로 콜로니를 클릭해 세는 도구입니다. 설치할 것이 없고, 사진은 PC 밖으로 나가지 않습니다.

1. 시작하기

  1. 받은 폴더에서 격자 콜로니 계수.html을 더블클릭합니다 (크롬 또는 엣지).
  2. 위쪽 사진 열기로 배지 사진을 고르거나, 폴더 열기로 폴더째(하위 폴더 포함) 엽니다. 사진·폴더를 화면 어디에 끌어다 놓아도 됩니다. 몇 장이든 한꺼번에 넣으면 모두 왼쪽 목록에 뜹니다.
  3. 폴더째 열면 폴더 구조가 그대로 왼쪽 목록에 묶입니다 (예: 「261008_11회차 › PW 루프 › 사진」). 날짜·구역마다 같은 파일 이름이 있어도 서로 섞이지 않습니다.
  4. 회차는 따로 적지 않습니다. 사진의 폴더·파일 이름에 있는 「N회차」를 자동으로 읽어 엑셀의 회차 열에 넣습니다.
순서 바꾸기: 왼쪽 목록의 사진을 마우스로 끌어 다른 사진 위에 놓으면 그 자리로 옮겨집니다. 다른 폴더의 사진 위에 놓으면 그 폴더로 옮겨집니다. 바꾼 순서는 저장됩니다.
폴더로 묶기: 목록에서 사진을 체크하고 「체크한 사진 폴더 지정」을 누른 뒤 「상위/하위」처럼 / 로 나눠 적으면(예: 261008_11회차/PW 루프) 그 폴더로 묶입니다. 찍은 점도 함께 옮겨집니다. 폴더 머리글을 누르면 접고 펼 수 있고, 머리글의 체크칸으로 그 폴더 사진을 한꺼번에 체크합니다.
사진을 열면 막(흰 원판)과 인쇄된 격자를 자동으로 찾아 맞춥니다. 어긋나면 오른쪽 2. 격자 맞추기에서 「인쇄 격자 자동 맞춤」을 다시 누르거나, 교차점 2점 클릭·미세조정으로 고칩니다.
격자가 필요 없는 판: 사진 위 도구줄의 「격자·원 없애기」 또는 오른쪽 2. 격자 맞추기의 「이 판 격자·원 없애기」(또는 체크한 사진 전부: 「체크한 사진 격자·원 없애기」)를 누르면 격자와 막 테두리 원이 지워지고, 합계는 찍은 점 개수로 셉니다. 「새로 여는 사진은 격자·원 없이」를 체크하면 앞으로 여는 사진은 처음부터 격자 없이 열립니다. 다시 필요하면 「격자·원 다시 표시」 또는 「인쇄 격자 자동 맞춤」을 누릅니다.

2. 세기

할 일방법
콜로니 세기콜로니를 클릭 → 주황 고리. 칸 오른쪽 위에 칸별 개수가 나옵니다.
잘못 찍은 점 지우기주황 고리 위를 다시 클릭, 또는 Ctrl+Z (마지막 점 취소)
화면 이동·확대좌클릭 끌기 = 이동, 휠 = 확대/축소, F = 막 전체 보기

전체화면위쪽 오른쪽 「⛶ 전체화면」 = 브라우저 주소창·탭을 숨기고 프로그램만 화면 가득 (메뉴는 그대로). 다시 누르거나 Esc·F11 = 원래대로

계수 끝 표시왼쪽 목록의 ✔ 동그라미, 사진 위 「✔ 계수 완료」, 또는 C

3. 다른 프로그램으로 센 사진

  • 다른 계수 프로그램이 콜로니마다 색 점·동그라미를 그려 둔 사진이면, 오른쪽 「다른 프로그램으로 센 사진」에서 표시 점 자동 세기를 누릅니다. 사진에서 표시 색을 스스로 찾아 개수를 셉니다. 찾은 표시는 보라 고리로 보입니다.
  • 색을 잘못 고르면 색 찍어서 세기를 누르고 사진 위 표시 하나를 클릭합니다. 그 색으로 다시 셉니다.
  • 「열린 사진 전부」를 체크하면 목록의 사진(체크한 사진이 있으면 그 사진만)을 한꺼번에 셉니다.
  • 서로 붙은 표시는 크기로 나눠 세고, 펜 글씨처럼 길고 가는 획은 뺍니다. 틀린 점은 클릭해 지우거나 더하세요. 노란색(콜로니 색)과 파랑~보라색(날짜 등 펜 글씨 색) 표시는 자동으로 고르지 않으니, 그런 색 표시는 「색 찍어서 세기」로 세세요. 막을 크게 잘라 낸 사진도 사진 전체에서 찾습니다.
  • 엑셀에는 「다른 프로그램 표시 점」 열로 따로 나옵니다. 이 점은 학습에는 쓰지 않습니다.

4. 자동 계수 (선택)

  • N.C 대조 사진을 먼저 넣으면, 음성대조 판에도 있는 수준의 점은 콜로니로 세지 않습니다. N.C 사진이 없으면 옅고 작은 잡티를 빼고 뚜렷한 점(진하기 18·크기 60px 이상)만 셉니다. N.C 사진을 넣는 쪽이 더 정확합니다.
  • 확실한 점만 셉니다: 흐릿하거나 아주 작은 점(진하기 22 미만 또는 크기 60px 미만)은 세지 않습니다.
  • 물방울 흰 점(빛이 반사돼 하얗게 반짝이는 작은 점)은 작아도 콜로니로 셉니다. 넓은 빛 반사 자국과 막 가장자리 테두리는 세지 않습니다.
  • 학습 모델은 「새 판 예측」 점수(놓친 것과 헛점을 함께 따진 점수)가 0.5 이상일 때만 씁니다. 그보다 낮으면 기본 기준으로 셉니다.
  • 이미 센 점(직접 찍은 주황 점, 다른 프로그램 표시인 보라 점)이 있으면 그대로 두고, 그 자리를 뺀 나머지 콜로니만 새로 더합니다. 합계 = 이미 센 점 + 새로 찾은 점.
  • 막에 인쇄된 격자선의 점선 마크(선 위의 작고 색 없는 점)는 자동 계수에서 뺍니다.
  • 다른 프로그램이 찍어 둔 빨강·초록 같은 진한 표시는 자동 계수에서 빼고 알려 줍니다. 그런 사진은 「표시 점 자동 세기」로 세세요.
  • 「이 판 자동 계수」 → 하늘색 고리. 하늘색 점은 한 번 클릭으로는 지워지지 않아 그 옆에 놓친 콜로니를 주황 점으로 찍을 수 있습니다. 하나만 지우려면 더블클릭, 전부 지우려면 「이 판 자동 계수 지우기」를 누릅니다.
  • 직접 센 점이 있는 상태에서 자동 계수를 돌렸을 때, 직접 점과 자동 점이 반 이상 겹치면 빨간 고리 하나로 표시하고 1개로 셉니다 (비교용). 자동 계수 뒤에 찍은 주황 점은 하늘색 점과 겹쳐도 합치지 않고 각각 셉니다.
  • 점수 = 일치율: 직접 계수한 콜로니 중 자동 계수도 찾은 비율입니다 (예: 직접 20개 중 19개 찾음 → 95점). 직접 계수에 없는 자동 점은 점수에 넣지 않습니다.
  • 자동 계수 학습: 학습하려면 직접 계수(주황 점)를 끝낸 판이 최소 1판 있어야 합니다. 그 판에서 「이 판으로 학습」을 누르면(또는 ✔ 완료 표시 시 자동) 직접 점을 정답으로 삼아, 자동 계수 후보 점 하나하나가 콜로니인지 아닌지 가려내는 모델을 다시 맞춥니다. 놓친 콜로니뿐 아니라 없는 곳에 찍은 점(헛점)도 감점합니다.
  • 학습이 효과 있는지 확인: 학습 칸의 표에서 「학습 전 기본」과 「새 판 예측(검증)」을 비교합니다. 새 판 예측은 판 하나씩 빼고 학습해 그 판을 맞혀 본 결과라, 처음 보는 판에서의 실력입니다 (2판 이상 학습하면 나옴). 새 판 예측이 학습 전보다 좋을 때만 자동 계수에 학습 모델을 쓰고, 아니면 기본 기준으로 셉니다. 판을 많이 학습시킬수록 좋아집니다.
  • 맞춘 기준은 「학습 기준 내보내기/가져오기」로 다른 사람과 나눌 수 있습니다.
자동 계수는 보조 도구입니다. 결과는 반드시 눈으로 확인하고, 기록에는 직접 확인한 수를 쓰십시오.

5. 결과 내보내기

  • 엑셀 시트 만들기 (위쪽 오른쪽): 명인제약_PQ_정제수_DATA 「미생물」 시트와 같은 양식으로 만듭니다. 행 = 채취 위치(No. 3 ACF-SV1 ~ 68 4HE-SV2 순서), 열 = 1~28회차, 회차 아래 줄 = 날짜. 회차·날짜는 폴더·파일 이름에서(예: 261005_Phase1_8회차), 위치는 파일 이름에서(예: 5-1_2WS-SV1 → 2WS-SV1) 읽습니다. 같은 회차·위치 사진이 원본·확대본 둘 다 있으면 센 쪽(둘 다 셌으면 확대본) 값을 씁니다. 목록에 없는 위치와 N.C는 맨 아래에 붙습니다. 아직 안 센 판은 빈칸. 두 번째 「사진별 목록」 시트에는 사진마다 회차·라벨·콜로니 수가 나옵니다. 사진을 일부만 체크해 두면 그 사진만 만들지 물어봅니다.
  • 표시 사진 저장 (오른쪽 아래): 왼쪽 체크칸으로 고른 사진을 원본 크기 + 점·격자·콜로니 수가 적힌 JPG로 저장
  • 목록에서 빼기: 체크 후 「체크한 사진 빼기」 (원본 파일과 찍은 점은 그대로). 잘못 뺐으면 목록 아래 「빼낸 사진 복원」에서 체크해 되살립니다.

6. 업데이트

  • 위쪽 오른쪽 업데이트 버튼 아래에 지금 버전이 보입니다. 인터넷이 켜져 있으면 프로그램을 열 때와 켜 둔 동안 30분마다 새 버전을 확인합니다. 새 버전이 나오면 화면 위에 알림 띠가 뜨고, 「지금 업데이트」를 누르면 바로 바뀝니다(찍어 둔 점은 그대로). 「나중에」를 누르면 다음에 열 때 다시 알려 줍니다.
  • 업데이트 → 새 버전 확인을 누르면 새 버전을 받아 바로 바뀝니다. 「받은 업데이트 파일로 바꾸기」로 카톡 등으로 받은 html 파일을 골라도 됩니다.
  • 프로그램 파일 자체는 그대로 두고 새 버전을 이 브라우저에 보관해 씁니다 (윈도우가 막지 않게). 찍은 점·사진 목록·학습 자료도 그대로 남습니다.
  • 문제가 생기면 「이전 버전으로 되돌리기」를 누릅니다.
  • 압축 파일 안에서 바로 열지 마세요. 꼭 「압축 풀기」 한 뒤 풀린 폴더의 프로그램을 여세요 (압축 안에서 열면 화면 아래에 경고가 뜹니다).

7. 알아둘 점

  • 저장 위치는 그 PC의 그 브라우저입니다. 다른 PC나 다른 브라우저로는 이어지지 않으니, 넘길 때는 엑셀 시트로 내보내 전달하세요.
  • 브라우저의 "인터넷 사용 기록 삭제(쿠키·사이트 데이터)"를 하면 저장된 작업도 지워집니다.
  • 글꼴은 인터넷에서 받아오며, 인터넷이 없으면 맑은 고딕으로 보입니다. 나머지 기능은 인터넷 없이 동작합니다.
  • 여러 파일을 한꺼번에 저장할 때 브라우저가 "여러 파일 다운로드 허용"을 물으면 허용을 누릅니다.
